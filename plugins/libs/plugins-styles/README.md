# Logos plugin-styles

This plugin contains a CSS file to help build the UI for Logos plugins.

### Getting started

Install the package:

```bash
npm install @logos/plugin-styles
```

Import the CSS file into your project:

```css
@import '@logos/plugin-styles/styles.css';
```

### Usage

For detailed examples and to see how to use the styles and components, visit the documentation at:

[Logos Plugin Styles Documentation](https://styles-doc.plugins.logos.app)

#### Icons

We recommend using Feather icons for Logos plugins to ensure consistency with Logos's design.

You can find Feather icons at: [Feather Icons](https://feathericons.com/)
