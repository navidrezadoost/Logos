# Figma Feature Parity Matrix — Reference Snapshot

**Snapshot date:** 2026-11-10
**Reference method:** public Figma product pages fetched on this date; these are current product/marketing pages, not a pinned Figma application build or exhaustive help-center specification. Feature availability by plan, beta status, and account configuration is not inferred. Matrix entries are a planning baseline, not a delivery promise.

## Status and estimate key

Logos status uses the P0 labels **Implemented**, **Verified**, **Blocked**, and **Proposed**. Estimates are relative engineering size (`S/M/L/XL`), not calendar commitments. “Fidelity target” records the behavior to measure, not achieved parity. Capability status is specifically the Logos status, not Figma’s rollout status.

## Reference caveats and release policy

The public pages above were fetched on 2026-11-10. They describe the advertised product surface but are not a versioned reference build, exhaustive specifications, or verification of plan availability, beta access, API access, or behavior in a specific account. Before declaring parity, pin a reference version/date and collect test files/video/interaction outcomes for the exact scope (start with Figma Design, not every adjacent product). Logos’ current reference fidelity is **unmeasured** except for the isolated Skia solid-rectangle pixel smoke.

Do not use the matrix as a promise to ship every suite product. First pass P0 entrypoint/schema/ownership, then P1 core editing and history; migration and design-system research can proceed in parallel only where it does not assume an unapproved document contract.
