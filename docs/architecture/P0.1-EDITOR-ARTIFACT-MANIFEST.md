## Producer/consumer handoff gap

The historical `manage.sh::build-frontend-bundle` calls `build frontend` and moves `frontend/target/dist` to `bundles/frontend`. Current `manage.sh` still contains the same `frontend` target, but the approved current tree has no `frontend/` directory. Separately, current `logos-app/scripts/sync-logos-workspace.py` reads `logos-app/dist/js`, and `sync-spa-to-dist.py` invokes it there with `check=False`. No checked-in task currently bridges historical `frontend/target/dist` into the current `logos-app/dist` consumer. Even a successful historical build would need a separately reviewed, provenance-checked packaging handoff before the current route could load it.

## Producer steps and blocking observations

1. Historical `frontend/scripts/build` clears `node_modules`, calls `corepack install` and `pnpm install`, builds renderer WASM and MCP, runs Shadow-CLJS main/worker releases, builds libraries/assets, then syncs `resources/public` to `target/dist`.
2. At the exact historical SHA, frozen pnpm install fails because the frontend importer for `plugins/libs/plugins-runtime` is stale relative to its manifest. The check performed in this Track A worktree used pnpm 10.28.2 and `--ignore-scripts`; it exited before modifying tracked files or compiling.
3. Historical MCP has a distinct `@logos` manifest versus `@penpot` lock/source contract. F06 repaired only a disposable MCP experiment, not the frontend or current release contract.
4. Historical emsdk bootstrap is not pinned by the producer script. The local historical renderer wrapper hardcodes `/opt/emsdk/emsdk_env.sh`; this path and `emcc` were absent. Running `render-wasm/build` in the isolated historical worktree yielded:

   ```text
   WARNING: EMSDK not found at /opt/emsdk/emsdk_env.sh — skipping WASM build.
   ```

   The script returns success after this warning. The caller does not assert the renderer files exist before later steps.
5. On a clean current `logos-app` build, the React CI builds Vite and runs `sync-spa-to-dist.py`; the latter invokes `sync-logos-workspace.py` with `check=False`. It can upload the React SPA while legacy shell/modules remain absent. Do not treat its exit status as validation of this artifact manifest.
