## Decision

Previous F04/F06/F07 reports and this Track A source comparison show independent manifest/lock, package-identity, artifact-supply, toolchain, and output-handoff blockers. Under the no-substitution/no-unverified-mirror constraint, no authorized repair can currently be applied.

**Decision requested:** package/release owners must settle the frontend `plugins-runtime` contract and MCP package identity, and provide an approved way to verify the exact commit-pinned source archives. Do not regenerate a lock or substitute `@penpot`/`@logos` artifacts until that decision is documented. Keep `/workspace.html` and current routes intact. Option C remains a conditional strategy, not an implemented runtime.

## Runtime contract queue

- Current Go mounts a Transit adapter at `/api/main/methods/`, so some legacy RPC transport is intentionally retained. Static extraction found 24 direct command names in historical workspace data, with nine lacking same-named current Go routes (listed in the ADR). This is a contract-test queue, not proof every command is required or that an alternative does not exist.
- Legacy WebSocket source connects to `/ws/notifications?session-id=…`, sends Transit subscriptions, and resubscribes on reconnect. Go uses that route and message names, but there is no runtime handshake test. `CheckOrigin` is unconditional and `subscribe-file` has no file-permission check; do not expose this legacy service before a security fix and authorization tests.
- Go stores JSON `file_change` rows while legacy rows may be Transit+zstd. Undecodable history is skipped/non-fatal in the current Go rebase path; a complete legacy collaboration claim is not supported.
- The 104-byte shape base record and 160-byte fill record are source-aligned with the historical adapter and verified current renderer ABI; this does not cover all renderer APIs, text/fonts, image loading, worker startup, or actual legacy build output.

## Recovery gate and decision

Do not proceed to Shadow compilation by bypassing frozen-install errors. First obtain package-identity and archive-integrity decisions, then resolve the manifest/lock contract without version changes. Next build with an exact, isolated toolchain and make missing emsdk/assets fail closed. Hash all produced modules and validate every current consumer URL. Only then run an isolated browser test for login, deep link, API/WebSocket activity, renderer/worker initialization, edit/save/reload, and security behavior.

**Outcome:** source remains recoverable; the historical producer is not supportable as-is and no complete artifact exists. Option C remains conditional. Keep routes unchanged; no runtime, dependency, or schema changes are included. P0.2-A and M0/M1 remain open.
