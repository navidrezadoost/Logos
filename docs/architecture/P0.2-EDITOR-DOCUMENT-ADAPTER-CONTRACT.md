## Boundary ownership

This is a test contract over existing representations, not a new persistent document model:

```text
Historical/Go file.data (PostgreSQL authority)
  → [MISSING] validated Go → React projection adapter
  → React command/projection state
  → [PARTIAL] React scene upload to 104-byte shape + 4+160-byte fill ABI
  → Rust/Skia scene (rendering only)
  → Go update-file/revision
  → [PARTIAL] server fetch + React hydration + reload equivalence
```

Zustand remains UI/projection state, Postgres file data/revisions remain server authority, and the Rust renderer receives an ephemeral rendering projection. IndexedDB is a local snapshot/journal, not server acknowledgement. Do not let a test-only adapter become a second authoritative schema.

## Failure and loss policy

- Unsupported discriminants must return a structured error/loss entry; never fall back to a rectangle for persistence or claim parity.
- Preserve arbitrary legacy map data through Go normalization. If React/Rust cannot represent it, keep it in a sidecar/extension envelope approved by the canonical contract, or report it as lossy before user-approved conversion. The `extension-p0` fixture is the sentinel.
- Map the nil UUID page root explicitly. Distinguish “top-level on a page” from “parent is absent”; preserve sibling ordering.
- Keep source geometry in a canonical coordinate representation. Convert x/y/w/h, x1/y1/x2/y2, React bounds, Rust `Rect`, and f32 renderer records with explicit units and deterministic rounding.
- Keep semantic fill/token/component references separate from resolved renderer colors. The renderer record is not a substitute for the persisted semantic value.
- Treat undecodable competing revision history as a conflict/recovery requirement, not an empty conflict set.

## Unverified assumptions and decision requested

- The synthetic PR #55 vectors cover useful compatibility sentinels but do not establish compatibility with authentic Penpot files or every existing document capability.
- The compile-only React shape mirrors the shared JSON manually; no test currently prevents drift between them.
- Persistence ownership, unsupported-field envelope semantics, and the approved runtime strategy have not been finalized; a fixture contract must not become an implicit storage format.

**Decision requested:** approve the contract as a test plan only, designate the canonical document/runtime owners, and resolve unsupported-field and root-ownership semantics before production adapters or save/reload behavior are implemented.
