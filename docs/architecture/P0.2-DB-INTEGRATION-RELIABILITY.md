## B1 — profile test resource leak

In `TestUpdateProfileRoundTrip`, cleanup called `pool.QueryRow` for an `UPDATE` without scanning the row. That leaves the row result unconsumed and is consistent with the reported pool-cleanup timeout. Moving restoration into `t.Cleanup` and using `Exec` removes the unconsumed result and ensures restoration errors are reported.

The test now registers scoped `t.Cleanup`, executes the restore with `pool.Exec`, and reports restore errors through `t.Errorf`. The PATCH → GET assertion and original name restoration purpose are preserved.

While running the full DB suite, a separate stale assertion was uncovered: `GetTeamsHandler` intentionally returns HTTP 200 with an empty array for anonymous bootstrap (per its implementation comment), while `TestGetTeamsHandler_NoAuth` expected 401. The test was aligned to the existing handler contract; no runtime auth behavior changed.
