**Baseline:** `f309baa72fbcd66c81f9215e91d4e4e05461f846`

## Decision brief

Continue investigating **Option C — controlled hybrid transition** as a reversible planning direction, not as an implementation authorization. Do not switch the dashboard to React `WorkspacePage`, restore partial legacy assets, retire `/workspace.html`, or designate the current SPA as a complete editor. There is not yet an end-to-end browser editor with verified rendering, server persistence, Penpot document fidelity, authorization, and rollback.

The old `docs/architecture/P0.1-EDITOR-RUNTIME-ADR.md` remains a source-baseline decision. This package adds current P0.5 evidence and limits; it does not certify or replace that baseline.

## Conditional recommendation and gates

1. **Do not select A now:** frozen install and source/artifact gates remain blocked. Do not alter lockfiles, substitute packages, or fabricate modules.
2. **Do not select B as the complete editor now:** compilation and one browser persistence fixture do not prove production Canvas/root hierarchy, visual correctness, route hydration, feature preservation, or full save/reload.
3. **Keep C as the conditional investigation path only:** preserve current routes and persisted semantics; integrate one versioned capability at a time. Do not start a production hybrid route, schema transition, or runtime retirement without explicit owner approval.
4. Reconsider only after hosted React/Rust initial-and-updated pixel assertions pass without the test-only root bridge; the authenticated browser/API persistence test passes hosted; representative historical fixtures show no silent loss; WebSocket DB/Redis security/revision tests pass; source/artifact provenance is resolved; and a representative-file performance/rollback exercise is recorded.

There are no quantitative performance, cost, or rollback results in the current evidence. Those criteria remain open rather than inferred from unit tests or synthetic fixture success.
