## CI-only correction

The Rust job now prints the runner image and configured apt source/mirror URIs, then probes DNS and `InRelease` access for official `archive.ubuntu.com` and `security.ubuntu.com` endpoints. This probe is the required check that the runner can reach the proposed official path; its result is not yet available. If these official endpoints are not reachable, the job fails at the probe and does not install from another source.

If the probe succeeds, the dependency step uses a temporary apt source file and isolated apt index directory containing only official Ubuntu noble, updates, backports and security URLs, signed with the runner's Ubuntu archive keyring. It does not modify `/etc/apt` source files, disable signature verification, ignore apt exit codes, or add a mirror. Installed package versions are logged.

## Verification boundary

The change is a candidate until hosted CI verifies the DNS probe, official metadata fetch, apt package install, and downstream Rust/browser workflow. No local run can establish GitHub runner DNS behavior. If official endpoint probing fails, stop and request an approved pinned CI image; do not try a different mirror.

After the CI correction is reviewed/merged, update PR #64 from `main` and rerun all checks. Preserve the Rust/WASM and pixel assertions unchanged.
