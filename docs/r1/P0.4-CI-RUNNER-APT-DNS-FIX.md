## CI-only correction

The Rust job prints the runner image and configured apt source/mirror URIs, then probes DNS and `InRelease` access for official `archive.ubuntu.com` and `security.ubuntu.com` endpoints. If these official endpoints are not reachable, the job fails at the probe and does not install from another source. The successful runs above establish that the current hosted images can reach the proposed official path.

If the probe succeeds, the dependency step uses a temporary apt source file and isolated apt index directory containing only official Ubuntu noble, updates, backports and security URLs, signed with the runner's Ubuntu archive keyring. It does not modify `/etc/apt` source files, disable signature verification, ignore apt exit codes, or add a mirror. Installed package versions are logged.

## Verification boundary

The hosted checks verify the DNS probe, official metadata fetch, apt package install, and downstream standalone Rust/WASM/browser workflow. The qualification workflow also retains a manually dispatched recheck. If official endpoint probing fails in a future run, stop and request an approved pinned CI image; do not try a different mirror.
