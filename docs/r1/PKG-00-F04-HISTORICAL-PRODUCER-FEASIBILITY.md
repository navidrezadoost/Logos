## Executive result

The historical source is recoverable, but its locked build is **not reproducible as-is under the no-upgrade constraint**. A disposable Node 22 build attempt stopped at the first frozen pnpm install because the frontend workspace manifest and lockfile disagree. A separate frozen MCP install check found another manifest/lock mismatch. No Shadow-CLJS compilation, renderer build, bundle audit from generated output, or runtime test occurred.

This is **Outcome C for the historical snapshot under its current dependency contracts**, not evidence that the editor code itself fails to compile or that its runtime is incompatible. Do not repair lockfiles or substitute dependencies in this experiment. Return the dependency/build contract blocker to the product/release owner for an authorized resolution. Preserve the existing workspace route meanwhile; this result does not authorize retirement or integration.

## F04-F — Security and maintenance implications

- The Node build container received only the historical source and temporary cache mounts; its environment was explicitly cleared to the required build variables. No production credentials or database were mounted, and no port was published.
- The build stopped before `render-wasm` or Shadow-CLJS; no development listener started. Historical `frontend/shadow-cljs.edn` still configures nREPL on `0.0.0.0`. Any further compile attempt must isolate that listener (for example, compile with a network namespace limited to loopback or use an authorized loopback-only config overlay) and must not expose dev ports.
- The stale frontend and MCP lock entries are reproducibility blockers. Resolving them requires an explicitly approved, version-preserving manifest/lock reconciliation or authoritative package publication; neither was attempted. No dependency vulnerability audit was run.
- A supported producer still needs an owner for Shadow-CLJS/Clojure, pnpm, WASM/Emscripten, MCP/plugin packaging and compatibility maintenance. Backend/API and plugin-host compatibility remain untested.

## Exit decision

**Outcome C — the producer cannot be recovered as a complete build under this snapshot's current frozen dependency contracts.** The exact blocker is lock/manifest drift, with a second independent mismatch in MCP; the repository's pinned Docker toolchain bootstrap also hit reset GitHub downloads. This does not mean the source is missing: it remains recoverable at the recorded SHA. It means no complete artifact or runtime claim can be made without an authorized resolution of those contracts and a working toolchain environment.

Until then, keep the legacy workspace route and release gate unchanged. Do not regenerate locks, upgrade packages, wire partial bundles into CI, retire the route, or deploy. M0/M1 and the complete editor artifact gate remain open.
