## Source and integration audit

The reviewed implementation is in `backend-go/internal/server/server.go`,
`backend-go/internal/handler/notifications_ws.go`, its WebSocket tests, and the
stale-history paths in the file update handler. The router passes the configured
exact-origin allowlist into the WebSocket handler. Request Origin parsing fails
closed for absent, malformed, opaque, cross-origin, and scheme/port-mismatched
values; same-origin requests use request TLS state and Host. The handler does
not use `X-Forwarded-Proto` to authorize an Origin. Proxy deployments therefore
need explicit valid origins in `BACKEND_GO_WEBSOCKET_ALLOWED_ORIGINS`.

The subscription audit found authorization at subscribe time and again before
delivery, including serialized unsubscribe/delivery state. Team and file events
are classified before authorization, avoiding shared-UUID namespace confusion.
Disconnect, missed pong, ping failure, and write failure paths close the socket
and clean up the Redis Pub/Sub loop and subscriptions. File updates reject
incomplete or undecodable stale operation history with 409 before committing a
revision. Labeled snapshot rows are excluded from operation history.

The integration suite exercises the production `server.New` router with a real
WebSocket client, PostgreSQL session and permission rows, and Redis Pub/Sub.
The stale-history integration uses PostgreSQL and verifies rejection without a
revision or change-row mutation. Tests also document that session validity is
checked at WebSocket upgrade; session revocation is not continuously rechecked.

## Finding severity

No confirmed high-severity defect was found in the reviewed Origin, resource
authorization, stale-history, or subscription-cleanup implementation and its
covered paths. **Production approval remains blocked** because deployed values
and public upgrade behavior are unknown. This is an evidence gap, not a claim
that the deployment is secure. Known limitations are upgrade-time-only session
authentication and the separately documented best-effort legacy lagged-change
decoding path; neither is silently treated as covered by this audit.
